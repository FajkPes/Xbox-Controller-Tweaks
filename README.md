# Xbox Controller Tweaks

A Windows controller tuner for changing how stick inputs feel in games.

## Key features

- Adjust response curves and deadzones.
- Save profiles and forward rumble.
- Expose a virtual Xbox 360 controller.

## Get started

Download the ZIP from Releases and follow the setup guide. Some games may also see the physical controller.
